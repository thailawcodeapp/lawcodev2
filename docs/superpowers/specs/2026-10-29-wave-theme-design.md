## 1. ปัญหาและเป้าหมาย

ผู้ใช้วิจารณ์ว่าแอป "ดูโบราณ" เพราะพื้นสีกระดาษ ฟอนต์ Trirong ตัวเอียง หน้า home ที่เป็นรายการคั่นเส้นไม่มีภาพหรือการเคลื่อนไหว และ "เสียง" ซึ่งเป็นจุดขายเหลือแค่ปุ่มเม็ดเล็ก

เป้าหมาย: เพิ่มธีม **Wave** ที่ทันสมัยและใช้ง่าย และให้ทุกคนได้ธีมนี้เป็นค่าเริ่มต้น หน้าตาปัจจุบันคงไว้ในชื่อธีม **Classic**

ตัวเอกของ Wave มีสองอย่าง:
- **เทพีจากไอคอนแอปเป็นปุ่มเล่น** แตะแล้วหูฟังลอยจากตะขอขึ้นไปสวมหัว
- **คลื่นเสียง** แต่ละฉบับเป็นแถบคลื่นที่เติมสีตามที่ฟังไปแล้ว

## 2. โครงสร้างธีม

### 2.1 ค่าที่เก็บ

ทุกค่าเก็บใน settings ของ `AppContext` (localStorage `lawcode-eng-settings`) เฉพาะในเครื่อง ไม่ sync ขึ้น cloud

| ค่า | ชนิด | ค่าเริ่มต้น | ความหมาย |
|---|---|---|---|
| `theme` | `'classic' \| 'wave'` | ไม่มีค่า → `'wave'` | ผู้ใช้เดิมหลังอัปเดตก็ได้ Wave ค่าอื่นที่ไม่รู้จัก (รวม `'galaxy'`) ถือเป็น Wave |
| `waveMode` | `'auto' \| 'light' \| 'dark'` | `'auto'` | โหมดสีของ Wave ส่วน `auto` ตาม `prefers-color-scheme` ของเครื่อง |
| `reduceMotion` | `boolean` | ไม่มีค่า → ตาม `prefers-reduced-motion` ของเครื่อง | หยุดแอนิเมชันของเทพีและอีควอไลเซอร์ |

`isDarkMode` เดิมใช้กับ Classic อย่างเดียว ไม่ถูกแก้ กลับไป Classic แล้วได้โหมดเดิม

### 2.2 คลาสบน `<html>`

- **Classic:** คลาส `dark` ตาม `isDarkMode` เหมือนปัจจุบัน
- **Wave:** มีคลาส `theme-wave` เสมอ และมีคลาส `dark` เมื่อ `waveMode` เป็น `dark` หรือเมื่อ `waveMode` เป็น `auto` และเครื่องอยู่ในโหมดมืด ฟัง event `change` ของ `matchMedia('(prefers-color-scheme: dark)')` ด้วย จะได้สลับทันทีเมื่อเครื่องเปลี่ยนโหมด

ใช้คลาส `dark` เป็นฐานของ Wave โหมดมืด เพราะทุกหน้ามี class `dark:` เขียนไว้แล้ว แล้ว token ของ Wave ทับค่าสีอีกชั้น

### 2.3 สีและฟอนต์เป็น token

- สีใน `tailwind.config.js` เปลี่ยนจากค่าตายตัวเป็น `rgb(var(--c-<name>) / <alpha-value>)` ชื่อคลาส Tailwind เดิมใช้ต่อได้ทั้งหมด และ modifier เช่น `bg-paper-dk/30` ยังทำงาน
- `:root` ใน `index.css` ตั้งค่า Classic ให้เท่าค่าปัจจุบันทุกค่า ส่วน `html.theme-wave` และ `html.theme-wave.dark` ใน `src/styles/wave.css` ทับค่า
- ฟอนต์ใช้วิธีเดียวกัน ด้วย token สี่ตัว:

| token | Classic | Wave | ใช้ที่ |
|---|---|---|---|
| `--f-display` | Trirong | Anuphan | หัวข้อ |
| `--f-serif` | Trirong | Anuphan | ข้อความ UI ทั่วไปที่ใช้ `font-serif` |
| `--f-ui` | Sarabun | Anuphan | ปุ่ม ป้าย ตัวเลข |
| `--f-body` (ใหม่) | Trirong | IBM Plex Sans Thai Looped | **เนื้อตัวบท** ในหน้าอ่าน |

- `ReaderScreen.jsx` บรรทัด 420 เขียน `fontFamily: "'Trirong', Georgia, serif"` ไว้ตรง ๆ ต้องเปลี่ยนเป็น `var(--f-body)`
- สีที่เขียนตายตัวในหน้าที่ใช้ร่วมกัน ได้แก่ `AppTour`, `TtsPlayer`, `BookScreen`, `ReaderScreen`, `SearchScreen`, `SettingsScreen`, `StatsScreen` (`#a93225`, `#ece4d4`, `#bdb19a` และ `rgba(169,50,37,…)`) ย้ายมาใช้ token
  - `HomeScreen` และ `SelectScreen` ของ Classic ไม่ต้องแปลง เพราะ Wave มีหน้าของตัวเองแทน
  - `#e8821e` และ `#2d8c4a` เป็นสีสถานะจำได้/จำไม่ได้ ใช้ค่าเดิมทั้งสองธีม

### 2.4 ชุดสี Wave

ค่าจากต้นแบบ ทุกค่าเป็น `R G B` ตามรูปแบบ token

| token | สว่าง | มืด | บทบาทใน Wave |
|---|---|---|---|
| `paper` (พื้นหน้า / ตัวอักษรในโหมดมืด) | `244 242 238` | `241 237 230` | สว่าง: พื้น `#F4F2EE` · มืด: ตัวอักษร `#F1EDE6` |
| `card` | `255 255 255` | `30 28 26` | การ์ด |
| `ink` (ตัวอักษร / พื้นที่กลับสี) | `27 26 23` | `19 18 17` | สว่าง: ตัวอักษร `#1B1A17` · มืด: พื้นที่กลับสี |
| `ink-soft` (เส้นในโหมดมืด) | `107 103 94` | `45 42 38` | |
| `rule` | `230 225 215` | `45 42 38` | เส้นคั่น |
| `rule-soft` | `214 207 194` | `165 158 146` | สว่าง: เส้นขอบ (`border-rule-soft`) · มืด: ตัวอักษรรอง (`dark:text-rule-soft`) |
| `accent` (ทองสำหรับตัวอักษร) | `138 95 18` | `233 190 100` | `#8A5F12` / `#E9BE64` |
| `ochre` (ทองสำหรับพื้นปุ่ม) | `217 164 65` | `226 176 78` | `#D9A441` / `#E2B04E` |
| `dark-bg` | `19 18 17` | `19 18 17` | พื้นหน้าในโหมดมืด |
| `dark-card` | `30 28 26` | `30 28 26` | การ์ดในโหมดมืด |
| `paper-dk`, `ink-2` | `233 228 217` / `34 32 26` | `47 44 40` / `241 237 230` | รอง |

ตัวแปรเฉพาะ Wave (ไม่ใช่ token ของ Tailwind ใช้ใน `wave.css` และ component ของ Wave):
- `--w-track`: สว่าง `#E9E4D9`, มืด `#2F2C28` (แท่งคลื่นที่ยังไม่ฟัง)
- `--w-golds`: สว่าง `#F4E7CB`, มืด `#3A2F19` (ทองอ่อนสำหรับพื้นแคปซูลแท็บและแถวที่เลือก)
- `--w-shadow`: เงาการ์ดตามต้นแบบ

กติกาเสริมใน `wave.css`:
- `html.theme-wave .italic { font-style: normal }` (Anuphan ไม่มีตัวเอียง)
- พื้นปุ่มที่โค้ดเดิมเขียน `bg-accent` ใช้สีทองสด `ochre` แทน เพราะ `accent` ในโหมดสว่างเป็นทองเข้มสำหรับตัวอักษร (`html.theme-wave .bg-accent { background-color: rgb(var(--c-ochre)) }`)
- ตัวอักษรบนพื้นปุ่มทอง (`bg-ochre`, `bg-accent`) เป็นสีเข้ม `#1D1404` เสมอ
- เส้นหนาของหัวหน้าจอ (`border-b-2`, `dark:border-paper`) ใน Wave เป็นเส้นบาง 1px สี `rule`

### 2.5 ฟอนต์รวมในแอป

ติดตั้ง `@fontsource/anuphan@5.3.0` (น้ำหนัก 400, 500, 600, 700) และ `@fontsource/ibm-plex-sans-thai-looped@5.3.0` (400, 500) แล้ว import ใน `main.jsx` ไฟล์ฟอนต์ถูกรวมเข้า `dist` ใช้ได้ตอนออฟไลน์ ส่วน Trirong / Sarabun ของ Classic ยังโหลดแบบเดิม

### 2.6 ไม่กระพริบตอนเปิดแอป

- สคริปต์สั้น ๆ ใน `<head>` ของ `index.html` อ่าน `lawcode-eng-settings` แล้วติด `theme-wave` (และ `dark` ตามกติกาข้อ 2.2) ก่อน React โหลด
- splash ใน `capacitor.config.ts` เป็นสี `#131211` เพื่อให้ไม่สว่างวาบในโหมดมืด ข้อเสียคือผู้ใช้ Wave โหมดสว่างและ Classic จะเห็นจอเข้มแวบหนึ่ง
- สี status bar ตามโหมดที่แสดงอยู่จริง: Wave สว่างใช้ `#F4F2EE` ตัวอักษรเข้ม, Wave มืดใช้ `#131211` ตัวอักษรสว่าง

### 2.7 หน้าที่มี layout เฉพาะ Wave

| route | Classic | Wave |
|---|---|---|
| `/` | `HomeScreen` (เดิม ไม่แตะ) | `WaveHome` |
| `/select` | `SelectScreen` (เดิม หน้าตาและการทำงานเหมือนเดิม) | `WaveSelect` |
| อื่น ๆ ทั้งหมด | เดิม | เดิม เปลี่ยนแค่สีและฟอนต์ผ่าน token |

`App.jsx` เลือก component ตาม `settings.theme`

**หน้าฉบับและหน้าอ่านตัวบท** (`/code/:id`, `/code/:id/section/:sid`) ใช้ `BookScreen` / `ReaderScreen` ตัวเดิมทั้งสองธีม ต้นแบบมีหน้าฉบับแบบใหม่ (คลื่นใหญ่ ปุ่มฟังทั้งฉบับ) ไว้แค่สาธิตว่าแตะชื่อฉบับแล้วเปิดตัวบทได้ ไม่อยู่ในขอบเขตนี้ (ข้อ 9)

### 2.8 แถบล่าง

ใช้ `TabBar` ตัวเดิมทั้งสองธีม: หน้าแรก · เลือกฟัง · สถิติ · บุ๊กมาร์ก · ตั้งค่า (`/`, `/select`, `/stats`, `/bookmarks`, `/settings`)

ใน Wave:
- พื้นแถบเป็นสี `card` มีเส้นบนบาง 1px
- แท็บที่เลือกอยู่ไม่มีพื้นกลับสี แต่ไอคอนอยู่ในแคปซูลสี `golds` (ทองอ่อน) และตัวอักษรเป็นสี `accent` ตัวหนา
- ไอคอนเป็นเส้น 1.8px ตามต้นแบบ

## 3. หน้าแรก Wave

เรียงจากบนลงล่าง: `AdBanner` › ส่วนบน (hero) › `VoiceNewsCard` (ถ้ามี) › แถวโฟลเดอร์ › ห้องสมุดเสียง › `TabBar`

### 3.1 ส่วนบน (hero)

การ์ดมุมมน 30px ขอบซ้ายขวา 12px **พื้นเข้มเสมอทั้งสองโหมด** เหมือนพื้นดำของไอคอน:
- พื้นเป็น radial gradient `#2B2519 → #15130F → #0C0B09` มีขอบในสีทองจาง และมีแสงส่องสีทองจากมุมซ้ายบน
- **แถวบน:** คำทักทายตามเวลา (สวัสดีตอนเช้า/บ่าย/เย็น) ชื่อ "Juris **Voice**" (Voice สีทอง) และปุ่มค้นหาวงกลมที่ไป `/search`
- **แถวกลาง:** ปุ่มเทพี (ข้อ 3.2) ทางซ้าย ทางขวาเป็นข้อมูลคิว:
  - kicker สีทอง ตามสถานะ เช่น `ฟังต่อ · 4/10`
  - ชื่อคิว เช่น "สอบเนติ สมัย 78"
  - มาตราปัจจุบันไม่เกิน 2 บรรทัด เช่น "อาญา ม.290 ทำร้ายผู้อื่นจนเป็นเหตุให้ถึงแก่ความตาย"
  - ปุ่ม ⏮ ⏭ และข้อความ "เหลืออีก N มาตรา"
- **แถวล่าง: คลื่นของคิว** หนึ่งแท่งต่อหนึ่งมาตราในคิว
  - ความสูงแท่ง = `0.28 + 0.72·√(ความยาวตัวบท / ความยาวสูงสุดในคิว)`
  - มาตราที่ผ่านแล้วเป็นสีทอง แท่งปัจจุบันเติมสีทองตามเวลาที่เล่นไป และเต้นแบบอีควอไลเซอร์ระหว่างเล่น
  - ใต้แถบมีป้ายมาตราแรก "คิวที่ฟังค้างไว้" และมาตราสุดท้าย
  - คิวยาวเกิน 40 มาตรา แบ่งคิวเป็น 40 ช่วงเท่า ๆ กัน แต่ละแท่งแทนหนึ่งช่วง
- ตอนอยู่หน้าแรก `TtsPlayer` (แถบเล่นด้านล่าง) **ซ่อน** เพราะ hero ทำหน้าที่เป็นตัวเล่นอยู่แล้ว ส่วนหน้าอื่นยังแสดงเหมือนเดิม

สถานะของ hero (ตามตาราง "ปุ่มฟังต่อ" ข้อ 4.2):

| สถานะ | kicker | แตะเทพี |
|---|---|---|
| กำลังเล่น | `กำลังฟัง · i/n` | หยุดชั่วคราว |
| หยุดชั่วคราวกลางคิว | `ฟังต่อ · i/n` | เล่นต่อ (`resume`) |
| มีคิวค้าง (`done: false`) | `ฟังต่อ · i/n` | `playResume()` |
| คิวจบแล้ว | `ฟังจบแล้ว · n/n` | เล่นคิวเดิมตั้งแต่ต้น |
| ไม่มีคิว มีประวัติอ่าน | `ฟัง · อาญา ม.288` | เล่นมาตราที่อ่านล่าสุดมาตราเดียว |
| ไม่มีอะไรเลย | `เริ่มฟัง` | ไป `/select` |

ระหว่างข้อมูลกฎหมายยังโหลด ปุ่มเทพีกดไม่ได้ และแถวข้อมูลแสดง "กำลังโหลด…"

### 3.2 ปุ่มเทพี

**รูปทรง**
- สี่เหลี่ยมมุมมน 32px ขนาด 148px (รูปทรงเดียวกับไอคอนแอป) มีขอบทองบาง 1px และเงา
- ปุ่ม ▶ / ❚❚ สีทองขนาด 40px วางกลางขอบล่าง ล้นขอบออกมา 16px ไม่ทับหูฟังที่แขวนอยู่ด้านขวา
- ทั้งก้อนเป็นปุ่มเดียว `aria-label` ตามสถานะ เช่น "ฟังต่อ" / "หยุดชั่วคราว"

**ภาพ** (ทำจากภาพที่ผู้ใช้สั่ง AI แล้วประมวลด้วย `store-assets/hero/processed/hero_assets.py` ย้ายไปไว้ที่ `src/assets/wave/`)

| ไฟล์ | ขนาด | เนื้อหา |
|---|---|---|
| `themis-base.jpg` | 640×640 | เทพี ตะขอว่าง ไม่มีหูฟัง |
| `themis-on.jpg` | 640×640 | ภาพเดียวกันที่แทนเฉพาะช่วงหัวด้วยภาพสวมหูฟังแบบ A ตะขอจึงเหมือน `themis-base.jpg` ทุกพิกเซล |
| `headphones.png` | 398×449 พื้นใส | หูฟังที่ตัดออกมา |

`store-assets/` อยู่ใน `.gitignore` ไฟล์ทั้งสามจึงต้องคัดลอกเข้า `src/assets/wave/` แล้ว commit ส่วนภาพต้นฉบับกับสคริปต์ยังอยู่ใน `store-assets/hero/` (ไม่อยู่ใน git)

**เลเยอร์** จากล่างขึ้นบน (ทุกเลเยอร์เต็มกรอบ ยกเว้นหูฟัง):
1. `themis-base.jpg`
2. `themis-on.jpg` ความทึบ 0 ตอนหยุด
3. หูฟัง `headphones.png` ห่อในกล่องสามชั้น (`fx` › `fy` › `fs`) ให้ขยับแกน X แกน Y และขนาดแยกกันได้
   - ตำแหน่งตอนแขวน: กล่องกว้าง 19.5% ของกรอบ มุมซ้ายบนที่ (66.9%, 64%) เอียง 7° รอบจุดกึ่งกลางขอบบน
   - หูฟังมีเงาเรืองทอง `drop-shadow(0 0 2px rgba(233,190,100,.8))`
4. คลื่นเสียง SVG สีทอง 4 เส้นที่หูซ้ายขวา ความทึบ 0 ตอนหยุด

**แอนิเมชัน** (แตะเพื่อเล่น)
- `fx` → `translateX(-147.5%)` ใช้เวลา 0.9s easing `cubic-bezier(.55,0,.35,1)` (ออกตัวช้า)
- `fy` → `translateY(-256%)` ใช้เวลา 0.9s easing `cubic-bezier(.1,.8,.3,1)` (ยกขึ้นเร็ว) สองแกนต่าง easing กัน ทางลอยจึงเป็นเส้นโค้ง
- `fs` → `scale(1.6, 1.2)` (เอียงกลับเป็น 0°) ใช้เวลา 0.9s แล้วจางหายใน 0.25s เริ่มที่ 0.85s
- `themis-on.jpg` ค่อย ๆ ปรากฏใน 0.35s เริ่มที่ 0.72s
- คลื่นเสียงปรากฏใน 0.4s เริ่มที่ 1.05s แล้วกระเพื่อมวนทุก 1.4s
- ภาพพื้นสว่างขึ้นจาก `brightness(.94)` เป็น `1.04` วงแหวนทองรอบปุ่มเต้นออกทุก 1.8s และแสงส่องบน hero ขยับช้า ๆ

**แตะเพื่อหยุด** ทำย้อนกลับ:
- `themis-on.jpg` จางออกใน 0.25s และหูฟังปรากฏบนหัวทันที
- หูฟังลอยกลับลงตะขอ เริ่มที่ 0.1s ใช้ easing เดิม

**ต้องไม่เล่นซ้ำโดยไม่ตั้งใจ**
- component ต้อง render ภาพในท่าเดิมก่อน แล้วเปลี่ยนคลาส `on` ในเฟรมถัดไป แอนิเมชันจึงจะเล่น
- การ render ซ้ำระหว่างเล่น (เช่น เปลี่ยนมาตรา) ต้องไม่ทำให้แอนิเมชันเล่นซ้ำ
- ต้นแบบเจอปัญหานี้ แก้ด้วยการจำท่าล่าสุดไว้ ใน React ทำได้ง่ายกว่า: เก็บท่าที่แสดงไว้ใน state แล้วเปลี่ยนใน `useEffect` หลัง commit

**ลดการเคลื่อนไหว:** ไม่มีการลอย ใช้แค่ภาพ `themis-base` ↔ `themis-on` เปลี่ยนทันที และไม่มีคลื่น วงแหวน หรืออีควอไลเซอร์

### 3.3 แถวโฟลเดอร์

- หัวข้อ "โฟลเดอร์ของฉัน" กับลิงก์ "ดูทั้งหมด" ที่เปิด `/select` ในมุมมองโฟลเดอร์

- ถ้าทุกโฟลเดอร์ว่าง ซ่อนทั้งแถว

### 3.4 ห้องสมุดเสียง

- หัวข้อ "ห้องสมุดเสียง" กับคำอธิบาย "แตะแท่งคลื่นเพื่อไปที่หมวดนั้น"
- ใต้หัวข้อมีคำอธิบายสีหนึ่งบรรทัด: ยังไม่ฟัง · ฟังแล้ว (สีประจำฉบับ) · ความสูง = ความยาวเสียง
- **ประมวลกฎหมาย 4 ฉบับ:** การ์ดแถวสูง คลื่น 40 แท่ง สูง 32px
- **รัฐธรรมนูญและพระราชบัญญัติ:** หัวข้อย่อยพร้อมจำนวนฉบับ แต่ละฉบับเป็นการ์ดแถวบาง คลื่น 28 แท่ง สูง 18px
- **หัวการ์ด:** จุดสีประจำฉบับ ชื่อ (ประมวลใช้ `fullName` ส่วน พ.ร.บ. ใช้ `displayName`) และเปอร์เซ็นต์ที่ฟังแล้ว
  - **แตะหัวการ์ด → `/code/:id`** (หน้าฉบับ แล้วจากนั้นแตะมาตราเพื่ออ่านตัวบท)
- **แตะแท่ง →** ไป `/select` เปิดฉบับนั้น และไล่สารบัญลงไปถึงหมวดลึกสุดที่มีมาตราแรกของช่วง (ข้อ 5.1)

**คณิตของคลื่น** อยู่ใน `src/lib/wave.js` เป็นฟังก์ชันล้วนที่มีเทสต์

```
waveBars(sections, heardIds, nBars) → [{ from, to, height, heard }]
  n = min(nBars, sections.length)
  แท่ง k ครอบมาตราลำดับ floor(k·N/n) ถึง floor((k+1)·N/n) − 1   (แบ่งตามลำดับ เท่า ๆ กัน)
  len_k   = ผลรวมความยาวตัวบท (text.length) ในช่วง
  height  = 0.16 + 0.84·√(len_k / max len)        (เทียบภายในฉบับเดียวกัน)
  heard   = จำนวนมาตราในช่วงที่อยู่ใน heardIds / จำนวนมาตราในช่วง
```

- สีของแท่ง: พื้นเป็นสี `track` ทับด้วยสีประจำฉบับที่ความทึบ `heard = 0 ? 0 : 0.35 + 0.65·heard`
- **มาตราที่ "ฟังแล้ว"** คือมาตราที่มีใน `getAllStats()` ของ `src/lib/stats.js` ซึ่งนับตอนมาตราเริ่มเล่น ใช้ข้อมูลที่มีอยู่ ผู้ใช้เดิมจึงเห็นคลื่นเติมสีตั้งแต่วันแรก
- ความสูงคำนวณครั้งเดียวต่อฉบับเมื่อโหลดข้อมูลเสร็จ ส่วนสัดส่วนที่ฟังคำนวณใหม่เมื่อเริ่มมาตราใหม่หรือหยุดเล่น
- `pathToSection(toc, number)` ใน `wave.js` เดินสารบัญจากระดับบนลงไป เลือกโหนดแรกที่ช่วงมาตรา (`range.from`–`range.to`) ครอบเลขมาตรานั้น จนถึงโหนดที่ไม่มีลูก แล้วคืนเส้นทางเป็นรายการโหนด เปรียบเทียบเลขแบบ `29/1` ด้วยกติกาเดียวกับ `sectionsInRange` ใน `toc.js`

## 4. ปุ่มฟังต่อ (คิวที่ฟังค้าง)

ยกมาจาก Galaxy spec ข้อ 4 ทุกประการ สรุปส่วนที่ต้องทำ:

### 4.1 บันทึกคิว

ไฟล์ใหม่ `src/lib/resumeQueue.js` เก็บใน localStorage `lawcode-th-resume`:

```js
{ label, refs: [{ bookId, sectionId }, ...], index, done, updatedAt }
```

- `playSections(items, startIndex, { label })` ใน `TtsContext` บันทึกคิวใหม่**ก่อน** `tts.playItems`
- `label` ที่ผู้เรียกส่ง:
  - โฟลเดอร์/กลุ่ม = ชื่อโฟลเดอร์
  - ทั้งหมวด/ทั้งฉบับ = ชื่อหมวดหรือฉบับ
  - มาตราที่ติ๊ก = "มาตราที่เลือก N มาตรา"
  - ไม่ส่งมา = "ชื่อย่อฉบับ ม.เลข" ของมาตราแรก
- `onItemStart` อัปเดต `index` เป็น `tts.currentItemIndex()` **ก่อน**เช็กโควตา
  - มาตราก่อน `index` ถือว่าฟังจบแล้ว
  - มาตราที่ `index` อาจฟังไม่จบ ฟังต่อจึงเริ่มจากต้นมาตรานั้น (หยุดระหว่างมาตรา 2 ของคิว 1–10 → เล่น 2–10)
- `onFinish` ตั้ง `done: true`
- การหยุดด้วยปุ่ม หยุดเพราะโควตา หรือปิดแอป ไม่แก้ `index`

### 4.2 กู้คิว

- `resolveResume(record, books)` ตัดมาตราที่ไม่มีในคลังแล้วทิ้ง และเลื่อน `index` ถอยตามจำนวนมาตราที่หายไปก่อนตำแหน่งนั้น ถ้าคิวจบแล้วหรือไม่เหลือมาตราคืน `null`
- `useTts()` เพิ่ม `playResume()` (คืน `false` ถ้าไม่มีอะไรให้ฟังต่อ) และ `resumeQueue` (ค่าจาก `getResume()` ตอน render)
- คิวที่มาตราหายหมดถูกลบ แต่เฉพาะเมื่อข้อมูลกฎหมายโหลดเสร็จแล้ว
- ปุ่ม "ฟัง" ในหน้าแรกของ Classic ไม่เปลี่ยน แต่ Classic ยังบันทึกคิวด้วย เพราะบันทึกอยู่ใน `TtsContext`

## 5. หน้าเลือกฟัง Wave

### 5.1 ลำดับการใช้งาน

1. **เลือกฉบับ:** แถวชิปเลื่อนข้างครบทุกฉบับ (จุดสี + `shortLabel`) ชิปที่เลือกเป็นพื้นกลับสี และเลื่อนเข้ากลางจอเมื่อเปลี่ยน
2. **คลื่นของฉบับที่เลือก:**
   - การ์ดมีชื่อ (`displayName`) และ "ฟังแล้ว x%"
   - คลื่น 40 แท่ง สูง 54px แบบเดียวกับหน้าแรก ใต้คลื่นมีป้าย "ม.แรก · แตะแท่งเพื่อไปที่หมวด · ม.สุดท้าย"
   - แตะแท่งแล้วไล่สารบัญลงไปถึงหมวดลึกสุดที่มีมาตราแรกของช่วง แท่งที่แตะกระพริบขอบทอง และมี toast "ไปที่ อาญา · หมวด 4 (ม.130)"
3. **ซูมสารบัญ:**
   - แต่ละระดับ (ภาค › ลักษณะ › หมวด) เป็นการ์ดสองคอลัมน์ แสดง "ภาค 2", ชื่อ และ "ม.107–366/4" แตะเพื่อลงหนึ่งชั้น
   - มีการ์ดทองท้ายตาราง "▶ ฟังทั้งฉบับ / ฟังทั้งหมวด · N มาตรา"
   - แถวเส้นทางพร้อมปุ่ม ‹ ใช้ย้อนกลับหนึ่งชั้น หรือปัดจากขอบซ้าย
   - มีช่องค้นเลขมาตราหรือคำในฉบับนี้
4. **ติ๊กมาตรา:**
   - ที่ระดับล่างสุดมีแถว "เลือกทั้งหมวด x/y" พร้อมปุ่ม ▶ ฟังทั้งหมวด ต่อด้วยรายการมาตรา (วงกลมติ๊ก, เลขมาตราสีทอง, ชื่อ, จุดสีถ้าฟังแล้ว)
   - ติ๊กข้ามหมวดและข้ามฉบับได้
   - แถบลอยเหนือแถบล่าง: `เลือก N · ล้าง · ＋ เพิ่ม · ▶ ฟัง`
5. **Popup โฟลเดอร์:** ตามข้อ 5.2

### 5.2 Popup โฟลเดอร์ (`FolderPickerSheet.jsx`)

ยกมาจาก Galaxy spec ข้อ 5.2 ทุกประการ สรุป:
- เด้งขึ้นจากด้านล่าง ใช้ `BottomSheet` ปิดด้วยการปัดลงหรือแตะพื้นหลัง หัวแผ่นเป็น "เพิ่ม N มาตราใน…"
- **ใช้ล่าสุด:** สูงสุด 3 โฟลเดอร์ เก็บใน localStorage `lawcode-th-folder-recent`
- **สถิติ:** แต่ละแถวบอก "จะลงใน › ฉบับ…" เพิ่มด้วย `addSectionsToGroup`
- **โฟลเดอร์ของฉัน:** โฟลเดอร์ระดับบนที่ผู้ใช้สร้าง
- **ไม่แสดง** "จำไม่ได้" และโฟลเดอร์ `readOnly` อื่น
- แต่ละแถวบอกจำนวนมาตรา และ "มี ม.x อยู่แล้ว" ถ้ามีมาตราที่เลือกอยู่แล้ว
- ติ๊กได้หลายโฟลเดอร์ ยืนยันด้วยปุ่ม "เพิ่มใน M โฟลเดอร์"
- **"โฟลเดอร์ใหม่…"** เป็นฟีเจอร์ Pro: คนที่ไม่ใช่ Pro เห็น `ProGateModal` / `SignInGateModal` ส่วน Pro ตั้งชื่อในแผ่นแล้วโฟลเดอร์ใหม่ถูกติ๊กให้ทันที
- **หลังยืนยัน:** toast "เพิ่ม N มาตราใน M โฟลเดอร์แล้ว" พร้อมปุ่ม "เลิกทำ" ที่ลบเฉพาะคู่ (โฟลเดอร์, มาตรา) ที่เพิ่งเพิ่ม แล้วล้างการติ๊ก
- `showToast(message, { action: { label, onPress } })` เพิ่มพารามิเตอร์ที่สามแบบไม่บังคับ การเรียกแบบเดิมทำงานเหมือนเดิม

### 5.3 โฟลเดอร์ของฉัน

ปุ่ม 📁 มุมขวาบนสลับไปมุมมองโฟลเดอร์ (state ภายในหน้า):
- แต่ละโฟลเดอร์เป็นการ์ดมีปุ่ม ▶ วงกลมทอง
- กลุ่มสถิติแสดงชิปตามฉบับ (จุดสี + ชื่อย่อ + จำนวน) แตะชิปเพื่อเล่นเฉพาะฉบับนั้น
- แตะการ์ดโฟลเดอร์ของผู้ใช้เปิด `FolderEditModal` ตัวเดิม
- ลิงก์ "ดูทั้งหมด" ในหน้าแรกเปิดมุมมองนี้โดยตรง

### 5.4 แยก logic ที่ใช้ร่วมกับ Classic

ดึงออกจาก `SelectScreen.jsx` เป็น hook ตาม Galaxy spec ข้อ 5.4:
- `useTocNavigation({ activeBook, filter })`
- `useSectionSelection({ activeBook, visibleSections })` บนฟังก์ชันล้วน `src/lib/selection.js`
- `useFolderPlayback({ books, folders, selectedList })` ที่ส่ง `label` ตามข้อ 4.1 และมี `playRefs(source, label, refs, emptyMessage)`

`SelectScreen` ของ Classic ต้องหน้าตาและทำงานเหมือนเดิมทุกอย่างหลังแยก

### 7.2 ตรวจด้วยตา

- **Classic ไม่เปลี่ยน:** ถ่ายภาพ 8 หน้า (home, select, book, reader, search, stats, bookmarks, settings) ทั้งโหมดสว่างและมืด ก่อนและหลังเปลี่ยนเป็น token แล้วต้องเหมือนกัน
- **Wave ทั้งสองโหมด:** ทุกหน้า ทุก modal และ bottom sheet, `TtsPlayer`, `AppTour` ต้องไม่มีตัวอักษรกลืนกับพื้น และไม่มีสีกระดาษหรือแดงชาดหลงเหลือ
- **เทพี:**
  - หูฟังตอนแขวนต้องคล้องกับตะขอพอดี
  - ตอนจบต้องแนบหัวโดยไม่เห็นภาพซ้อน
  - เล่นแล้วหยุดถี่ ๆ ต้องไม่ค้างครึ่งทาง
  - เปลี่ยนมาตราระหว่างเล่นต้องไม่ทำให้แอนิเมชันเล่นซ้ำ
- **บนเครื่องจริง (ผู้ใช้ทำ):**
  - แอนิเมชันเทพีและอีควอไลเซอร์ลื่นบน Android รุ่นช้า
  - hero ไม่ล้นจอบน iPhone/iPad ทุกขนาดตัวอักษร
  - เปิดแอปตอนออฟไลน์แล้วฟอนต์ยังถูก
  - ไม่มีจอสว่างวาบตอนเปิดแอป

## 8. กรณีผิดพลาด

| กรณี | พฤติกรรม |
|---|---|
| ข้อมูลกฎหมายยังโหลดไม่เสร็จ | hero แสดง "กำลังโหลด…" และกดเทพีไม่ได้ คลื่นแสดงเป็นแท่งความสูงเท่ากันสีจาง จนกว่าจะโหลดเสร็จ |
| ภาพเทพีโหลดไม่ได้ | ภาพถูก bundle มากับแอป จึงไม่ควรเกิด ถ้าเกิด ปุ่ม ▶ ยังกดได้ตามปกติ |
| ฉบับ `available: false` | คลื่นจาง แตะแล้ว toast "เร็ว ๆ นี้" |
| อ่าน/เขียน localStorage ไม่ได้ | ใช้ค่าเริ่มต้น (Wave, ตามเครื่อง, ไม่มีคิวค้าง) ไม่พัง |
| สารบัญโหลดไม่สำเร็จ | "โหลดสารบาญไม่สำเร็จ" พร้อมปุ่มลองใหม่ แตะแท่งคลื่นแล้วเปิดฉบับนั้นที่ระดับบนสุดแทน |
| โฟลเดอร์ถูกลบจากอีกเครื่องระหว่างเปิด popup | เพิ่มเฉพาะโฟลเดอร์ที่ยังมีอยู่ toast บอกจำนวนที่เพิ่มจริง |
| ฟังอยู่เบื้องหลังนานจน JS หยุด (Android ราว 80 วินาที) | `index` ตามทันเมื่อแอปกลับมา ผ่าน `enterNativeItem` ถ้าแอปถูกปิดทิ้งระหว่างนั้น ฟังต่ออาจย้อนไปไม่กี่มาตรา ยอมรับได้ |

## 9. ไม่อยู่ในรอบนี้

- หน้าฉบับแบบใหม่ (คลื่นใหญ่, ปุ่มฟังทั้งฉบับ) และหน้าอ่านแบบใหม่ที่เห็นในต้นแบบ รอบนี้ได้แค่สี ฟอนต์ และฟอนต์ตัวบทแบบ Looped
- ออกแบบ `TtsPlayer` ใหม่
- ธีม Galaxy (spec และแผนเก็บไว้ใน branch `feat/galaxy-theme`)
- Sync ค่าธีม โหมดสี และคิวฟังต่อขึ้น cloud
- ปุ่มฟังต่อแบบคิวในหน้าแรกของ Classic
- ใช้ภาพเทพีเป็นไอคอนแอปหรือ splash ใหม่
