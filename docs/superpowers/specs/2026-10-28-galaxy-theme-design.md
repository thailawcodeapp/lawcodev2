## 1. ปัญหาและเป้าหมาย

ผู้ใช้วิจารณ์ว่าแอป "ดูโบราณ" ต้นเหตุคือพื้นสีกระดาษ `#ece4d4` ฟอนต์ Trirong ที่มีหัวและใช้ตัวเอียงเยอะ หน้า home ที่เป็นรายการคั่นเส้นไม่มีภาพหรือการเคลื่อนไหว และ "เสียง" ซึ่งเป็นจุดขายเหลือแค่ปุ่มเม็ดเล็กปุ่มเดียว

เป้าหมาย: เพิ่มธีมใหม่ชื่อ **Galaxy** หน้าตาเป็นอวกาศ มีระบบสุริยะ 3D ของกฎหมายเป็นหน้าแรก และให้ทุกคนได้ธีมนี้เป็นค่าเริ่มต้น หน้าตาปัจจุบันคงไว้ครบในชื่อธีม **Classic**

## 2. โครงสร้างธีม

### 2.1 ค่าธีม

- เพิ่ม `theme: 'classic' | 'galaxy'` ใน settings ของ `AppContext` (localStorage `lawcode-eng-settings`) ข้าง `isDarkMode`
- ไม่มีค่า → `'galaxy'` ผู้ใช้เดิมหลังอัปเดตก็ได้ Galaxy เปลี่ยนกลับได้ที่ ตั้งค่า › ธีม
- เก็บในเครื่องเท่านั้น ไม่ sync ขึ้น cloud
- `App.jsx` ติดคลาส `theme-galaxy` บน `<html>` แบบเดียวกับที่ติดคลาส `dark` อยู่ตอนนี้

### 2.2 สีและฟอนต์เป็น token

- สีใน `tailwind.config.js` เปลี่ยนจากค่าตายตัวเป็นตัวแปร CSS เช่น `paper: 'var(--c-paper)'` ชื่อคลาส Tailwind เดิมทั้งหมดใช้ต่อได้
- `:root` (Classic สว่าง), `:root.dark` (Classic มืด) และ `:root.theme-galaxy` ตั้งค่าตัวแปรใน `index.css` ค่าของ Classic ต้องเท่าค่าปัจจุบันทุกค่า
- ฟอนต์ใช้วิธีเดียวกัน `font-display` / `font-serif` / `font-ui` อ่านจาก `--f-display` ฯลฯ Classic = Trirong / Sarabun, Galaxy = IBM Plex Sans Thai ทั้งหมด
- สีที่เขียนตายตัวในไฟล์ `.jsx` (`#a93225` 30 จุด, `#ece4d4` 10, `#bdb19a` 8, `#0f0e0c` 1 ใน 10 ไฟล์) ย้ายมาใช้ token ส่วน `#e8821e` และ `#2d8c4a` เป็นสีสถานะ (จำได้ / จำไม่ได้) ใช้ค่าเดิมทั้งสองธีม
- ชุดสี Galaxy: พื้น `#0a0e22`, พื้นการ์ด `#141a36`, ตัวอักษร `#e8e6f6`, รอง `#9da3cc`, เส้น `rgba(200,205,255,.12)`, เน้น `#f2a865`
- ผล: หน้าอ่าน ตัวเล่นเสียง ค้นหา สถิติ บุ๊กมาร์ก ตั้งค่า และ modal ทั้งหมดเปลี่ยนสีและฟอนต์ตามธีมโดยไม่แตะ layout

### 2.3 Galaxy มืดเสมอ

ในธีม Galaxy ซ่อนสวิตช์โหมดมืด/สว่างในหน้าตั้งค่า และ **ติดคลาส `dark` เสมอ** ไม่ว่า `isDarkMode` จะเป็นอะไร ทุกหน้าจึงใช้ class `dark:` ที่เขียนไว้แล้วสำหรับโหมดมืด แล้ว token ของ Galaxy (`html.theme-galaxy`) ทับค่าสีอีกชั้น ค่า `isDarkMode` ไม่ถูกแก้ กลับไป Classic แล้วได้โหมดเดิม

(แก้ระหว่างเขียนแผน: ฉบับแรกเขียนว่าไม่ติด `dark` แต่ class โหมดสว่างใช้ `ink` เป็นทั้งสีตัวอักษรและพื้นแถบที่กลับสี เช่น แท็บที่เลือกอยู่ ถ้าใช้โหมดสว่างเป็นฐาน แถบเหล่านั้นจะกลายเป็นแถบสีขาว)

### 2.4 ฟอนต์รวมในแอป

IBM Plex Sans Thai (น้ำหนัก 400, 500, 600, 700) ติดตั้งจากแพ็กเกจ `@fontsource/ibm-plex-sans-thai@5.3.0` แล้ว import ใน `main.jsx` ไฟล์ฟอนต์ถูกรวมเข้า `dist` ตอน build ไม่โหลดจาก Google Fonts เพราะเปิดแอปตอนออฟไลน์แล้วฟอนต์จะกลายเป็นฟอนต์ระบบ Trirong / Sarabun ของ Classic ยังโหลดแบบเดิม

### 2.5 มืดตั้งแต่เฟรมแรก

- สคริปต์สั้น ๆ ใน `<head>` ของ `index.html` อ่าน `lawcode-eng-settings` แล้วติด `theme-galaxy` ก่อน React โหลด เงื่อนไขเดียวกับ 2.1 (ไม่มีค่า = Galaxy)
- `capacitor.config.ts` เปลี่ยน `backgroundColor` ของ splash ทั้งสองที่จาก `#ece4d4` เป็น `#04060e` ผู้ใช้ Classic จะเห็นจอเข้มแวบหนึ่งตอนเปิดแอป ยอมรับได้

### 2.6 หน้าที่มี layout เฉพาะ Galaxy

| route | Classic | Galaxy |
|---|---|---|
| `/` | `HomeScreen` (เดิม ไม่แตะ) | `GalaxyHome` |
| `/select` | `SelectScreen` (เดิม หน้าตาและการทำงานเหมือนเดิม) | `GalaxySelect` |
| อื่น ๆ | เดิม | เดิม ใช้ token |

`App.jsx` เลือก component ตาม `settings.theme`

### 2.7 แถบล่าง

ใช้ `TabBar` ตัวเดิมทั้งสองธีม: หน้าแรก · เลือกฟัง · สถิติ · บุ๊กมาร์ก · ตั้งค่า (`/`, `/select`, `/stats`, `/bookmarks`, `/settings`) Galaxy เปลี่ยนแค่สีผ่าน token

## 3. หน้าแรก Galaxy

### 3.1 ชิ้นส่วน

| ไฟล์ | หน้าที่ |
|---|---|
| `src/lib/orbit.js` | คณิตล้วน ไม่แตะ DOM: แปลงพิกัด 3D → จอ, แบ่งดาวลงวง, วางป้ายชื่อ มีเทสต์ |
| `src/components/galaxy/GalaxySky.jsx` | ฉากอวกาศเต็มจอ: พื้นไล่สี เนบิวลา ดาวสามชั้น (box-shadow) ดาวกะพริบ ดาวตก ยกจากกฎดิ |
| `src/components/galaxy/SolarSystem.jsx` | ดวงอาทิตย์ วงโคจร ดาว ป้ายชื่อ loop แอนิเมชัน |
| `src/screens/GalaxyHome.jsx` | ประกอบหน้า |

ลำดับในหน้า: `AdBanner` › แถบบน (ชื่อแอป, ปุ่ม ⚙ ไปหน้า "ดาวที่โคจร") › `VoiceNewsCard` (ถ้ามี) › ระบบสุริยะ › แถบชื่อฉบับ › รายการทุกฉบับพร้อมแถบความคืบหน้าการฟัง › `TabBar`

### 3.2 กล้องและการโคจร

ค่าคงที่ใน `orbit.js` ผู้ใช้ปรับไม่ได้:

- มุมก้ม 25°, บิดระนาบ −17°, ความลึก 88 (ระยะกล้อง `D = 900 − 88 × 6 = 372`), รอบละ 180 วินาที
- **ทั้งระบบหมุนพร้อมกัน** ทุกดาวใช้ความเร็วเชิงมุมเดียวกัน ระยะห่างระหว่างดาวจึงคงที่
- ดาววงติดกันวางเหลื่อมกันครึ่งช่อง (`phase = 2πq/c + (k mod 2)·π/c + 0.35k`)

การแปลงพิกัดของดาวรัศมี `r` มุม `θ`:

```
X = r cosθ,  Z = r sinθ                 (Z > 0 = ด้านหน้า)
y = Z sin(tilt),  zd = Z cos(tilt)
s = D / (D − zd)                        สเกลมุมมอง
(x, y) = หมุน (X·s, y·s) ด้วยมุม roll แล้วบวกจุดศูนย์กลาง
ขนาดดาว ×  s^2.2 × (0.78 + 0.32·near),  near = (sinθ + 1) / 2
```

- ดาวด้านหลังมืดลงตาม `near` (แผ่นดำโปร่งทับดาว ไม่ใช้ `filter`)
- แสงบนผิวดาวหันเข้าหาดวงอาทิตย์
- ลำดับซ้อน `z = 1000 + zd` ดวงอาทิตย์อยู่ที่ 1000 ดาวด้านหลังจึงลอดหลังดวงอาทิตย์
- วงโคจรครึ่งหลังวาดจาง (อยู่ใต้ดวงอาทิตย์) ครึ่งหน้าวาดชัดพร้อมแสงเรือง (อยู่เหนือดวงอาทิตย์) และมีแสงจาง ๆ บนระนาบ

### 3.3 แบ่งดาวลงวง

- จำนวนวงตามจำนวนดาว `n`: 1–3 → 1 วง, 4–7 → 2, 8–10 → 3, 11 ขึ้นไป → 4
- รัศมีวงในสุด 60 วงนอกสุด 126 (หน่วย px ของพื้นที่กว้าง 300) วงเดียวใช้ 95
- จำนวนดาวต่อวงแปรตามรัศมี ทุกวงมีอย่างน้อย 1 ดวง ผลรวมเท่า `n`
- ลำดับจากวงในไปวงนอกตาม `LAW_BOOKS_META`
- ขนาดดาว = `13 + 15·√(totalSections / 1755)`
- สีดาวต่อฉบับเพิ่มเป็น `orbitColor` ใน `lawMeta.js`

### 3.4 ป้ายชื่อ

ชื่อย่อเพิ่มเป็น `orbitName` ใน `lawMeta.js`:

แพ่ง · อาญา · วิแพ่ง · วิอาญา · รัฐธรรมนูญ · พระธรรมนูญ · แรงงาน · ศาลแขวง · ศาลปกครอง · ล้มละลาย · ลิขสิทธิ์ · ผู้บริโภค · ศาลเยาวชน

- **ทุกดวงมีป้ายตลอดเวลา**
- ทุกเฟรมวางป้ายจากดาวที่ใกล้ที่สุดไปไกลที่สุด แต่ละป้ายลองช่องตามลำดับ: ช่องที่ใช้เฟรมก่อน › ใต้ดาว › เหนือดาว › ขวา › ซ้าย แล้วเลือกช่องแรกที่ไม่ทับป้ายที่วางไปแล้วและไม่ล้นขอบ (ขอบละ 4px)
- ถ้าไม่มีช่องว่างเลย ใช้ช่องเดิมแต่ลดความทึบลงครึ่งหนึ่ง (ป้ายไม่หาย)
- ป้ายเลื่อนเข้าหาช่องใหม่แบบนุ่ม (เข้าใกล้ 18% ต่อเฟรม)
- ขนาดตัวอักษร `8.5 + 3·near` px ความทึบ `0.6 + 0.4·near`

### 3.5 การแตะ

- **พื้นที่แตะของดาวทุกดวงกว้างอย่างน้อย 44px**
- **แตะดาวครั้งแรก:** เลือกดาว (ขอบสีส้ม) แถบใต้ระบบแสดงชื่อเต็มและจำนวนมาตรา
- **แตะดาวที่เลือกอยู่ หรือแตะแถบ:** เปิด `/code/:id`
- **ฉบับ `available: false`:** ดาวจาง แตะแล้วแสดง toast "เร็ว ๆ นี้"
- **แตะดวงอาทิตย์:** ฟังต่อ ตามข้อ 4

### 3.6 ดาวที่โคจร

- เก็บเป็นรายการฉบับที่ซ่อน `orbitHidden: string[]` ใน settings (ไม่ใช่รายการที่แสดง) ฉบับใหม่ที่เพิ่มเข้าแอปภายหลังจึงขึ้นเป็นดาวเอง
- ค่าเริ่มต้น `[]` แสดงครบทุกฉบับ
- id ใน `orbitHidden` ที่ไม่มีในแอปแล้วถูกข้าม ถ้าซ่อนครบทุกฉบับให้แสดงฉบับแรก
- หน้าตั้งค่า (ปุ่ม ⚙ บนหน้าแรก และ ตั้งค่า › หน้าแรก (Galaxy) › ดาวที่โคจร) เป็น bottom sheet
  - มีสวิตช์ทีละฉบับ ปิดฉบับสุดท้ายไม่ได้
  - มีปุ่มลัด "ประมวล 4 + รธน." และ "ทั้งหมด"
  - ไม่มีการลากเรียงลำดับ
- ทุกฉบับยังอยู่ในรายการ "ทุกฉบับ" ใต้ระบบสุริยะเสมอ

### 3.7 ความลื่นและการหยุด

- ทุกเฟรมเปลี่ยนแค่ `transform`, `opacity` และ `z-index` (ลำดับซ้อนหน้า-หลัง) ไม่เปลี่ยน `filter`, `box-shadow` หรือ `background`
- พื้นที่แตะเป็นปุ่มใสขนาด 48px แยกจากตัวดาว เลื่อนด้วย transform อย่างเดียว ไม่ย่อขยายตามดาว พื้นที่แตะของดาวด้านหลังจึงไม่เล็กลง
  - แสงเรืองของดาวเป็น pseudo-element ที่ปรับ opacity
  - ทิศแสงบนผิวดาวหมุนด้วย transform ของชั้นไฮไลต์
- loop หยุดเมื่อออกจาก `/`, เมื่อ `document.hidden` และเมื่อเปิด "ลดการเคลื่อนไหว"
- **ลดการเคลื่อนไหว:** `reduceMotion` ใน settings เริ่มต้นตาม `prefers-reduced-motion` ของเครื่อง เปิดแล้วระบบค้างนิ่งที่ `θ` ชุดเริ่มต้น ป้ายครบ ดาวตกและเนบิวลาหยุด

## 4. ปุ่มฟังต่อ (ดวงอาทิตย์)

ฟังต่อ **ชุดมาตราที่ฟังค้างไว้** ไม่ใช่มาตราเดียว เช่น กำลังฟังโฟลเดอร์ที่มีมาตรา 1–10 แล้วหยุดระหว่างมาตรา 2 กดฟังต่อจะเล่น **มาตรา 2 ตั้งแต่ต้น แล้วต่อ 3–10** มาตราที่ฟังจบแล้วไม่เล่นซ้ำ และไม่ต้องเริ่ม 1 ใหม่

### 4.1 บันทึกคิวล่าสุด

ไฟล์ใหม่ `src/lib/resumeQueue.js` เก็บใน localStorage `lawcode-th-resume`:

```js
{
  label: 'สอบเนติ สมัย 78',             // ชื่อที่แสดงบนดวงอาทิตย์
  refs: [{ bookId, sectionId }, ...],  // คิวทั้งชุดตอนเริ่มเล่น
  index: 1,                            // มาตราที่กำลังเล่นหรือค้างอยู่
  done: false,                         // เล่นจบทั้งคิวแล้ว
  updatedAt: 1793200000000
}
```

- `playSections(items, startIndex, { label })` ใน `TtsContext` รับพารามิเตอร์ที่สามเพิ่ม (ไม่บังคับ) แล้วบันทึกคิวใหม่ทุกครั้งที่เริ่มเล่น
- `label` ที่ผู้เรียกส่งมา:
  - โฟลเดอร์ / กลุ่ม = ชื่อโฟลเดอร์
  - ทั้งหมวด / ทั้งฉบับ = ชื่อหมวดหรือฉบับ
  - มาตราที่ติ๊กเลือก = "มาตราที่เลือก N มาตรา"
  - มาตราเดียว = "ฉบับ ม.เลข"
  - ไม่ส่งมา = ชื่อฉบับและเลขของมาตราแรก
- `onItemStart` (ที่เรียก `recordListen` อยู่แล้ว) อัปเดต `index` เป็นมาตราที่เริ่มเล่น มาตราก่อนหน้า `index` ถือว่าฟังจบแล้ว มาตราที่ `index` อาจฟังไม่จบ จึงเริ่มจากต้นมาตรานั้น
- `onFinish` ของคิว (เล่นจบมาตราสุดท้ายโดยไม่มีเล่นซ้ำ) ตั้ง `done: true`
- การหยุดด้วยปุ่ม หยุดเพราะโควตาหมด หรือปิดแอป ไม่แก้ `index` คิวจึงค้างอยู่ที่มาตราที่เล่นค้าง

### 4.2 การแสดงผลและการกด

| สถานะ | ดวงอาทิตย์แสดง | กดแล้ว |
|---|---|---|
| มีคิวค้าง (`done: false`) | ▶ ฟังต่อ · `label` · `index+1`/`refs.length` | `buildItemsFromRefs(books, refs)` แล้ว `playSections(items, index, { label })` |
| กำลังเล่นอยู่ | ❚❚ · มาตราที่กำลังเล่น | หยุดชั่วคราว |
| คิวจบแล้ว หรือไม่มีคิว แต่มีประวัติอ่าน | ▶ ฟัง · มาตราที่อ่านล่าสุด | เล่นมาตรานั้นมาตราเดียว (เหมือนปุ่ม "ฟัง" ปัจจุบัน) |
| ไม่มีอะไรเลย | ▶ เริ่มฟัง | ไป `/select` |

- **มาตราในคิวถูกลบออกจากคลังแล้ว:** `buildItemsFromRefs` ข้ามมาตรานั้น และ `index` ต้องเลื่อนตามจำนวนมาตราที่หายไปก่อนตำแหน่งนั้น ถ้าไม่เหลือมาตราเลย ให้ลบคิวแล้วใช้แถวถัดไปของตาราง
- **โควตาและ Pro:** ทำงานผ่าน `playSections` เดิม จึงเหมือนการเล่นปกติทุกอย่าง
- ปุ่ม "ฟัง" ในหน้าแรกของ Classic ไม่เปลี่ยนในรอบนี้ แต่ Classic ยังบันทึกคิวด้วย เพราะบันทึกอยู่ใน `TtsContext`

## 5. หน้าเลือกฟัง Galaxy

### 5.1 ลำดับการใช้งาน

1. **เลือกฉบับ:** หัวหน้าเป็นวงโคจรเล็ก (ใช้ `orbit.js` ค่ากล้องชุดเดียวกัน วงเดียว) ปัดซ้ายขวาเพื่อเปลี่ยนฉบับ มีครบทุกฉบับ ไม่ขึ้นกับ `orbitHidden` ใต้หัวเป็นชื่อเต็มของฉบับ
2. **ซูมสารบัญ:** แต่ละระดับ (ภาค › ลักษณะ › หมวด) เป็นการ์ดสองคอลัมน์ แตะเพื่อลงไปหนึ่งชั้น ย้อนกลับด้วยปุ่ม ‹ หรือปัดจากขอบซ้าย
   - ทุกระดับมีการ์ด ▶ ฟังทั้งหมวด / ทั้งฉบับ
   - มีช่องค้นเลขมาตราหรือคำในฉบับนี้
3. **ติ๊กมาตรา:** ที่ระดับล่างสุดเป็นรายการมาตราเต็มความกว้าง มีแถว "เลือกทั้งหมวด"
   - ติ๊กข้ามหมวดและข้ามฉบับได้ (คีย์ `bookId::sectionId` เดิม)
   - เลือกแล้วมีแถบลอย: `เลือก N · ล้าง · ＋ เพิ่ม · ▶ ฟัง`
4. **Popup โฟลเดอร์:** กด "＋ เพิ่ม" แล้วตามข้อ 5.2
5. **หลังเพิ่ม:** toast "เพิ่ม N มาตราใน M โฟลเดอร์แล้ว" พร้อมปุ่ม "เลิกทำ" แล้วล้างการติ๊ก

### 5.2 Popup โฟลเดอร์ (`FolderPickerSheet.jsx`)

Bottom sheet เด้งขึ้นจากด้านล่าง ใช้ `BottomSheet` ที่มีอยู่ ปิดด้วยการปัดลงหรือแตะพื้นหลัง

- หัว: "เพิ่ม N มาตราใน…"
- **ใช้ล่าสุด:** ไม่เกิน 3 โฟลเดอร์ จาก localStorage `lawcode-th-folder-recent` (id ใหม่สุดก่อน)
  - อัปเดตทุกครั้งที่เพิ่มสำเร็จ
  - ข้าม id ที่ถูกลบไปแล้ว
  - ไม่แก้ schema โฟลเดอร์ที่ sync ขึ้น cloud
- **สถิติ:** กลุ่ม `grp-nethi`, `grp-attorney`, `grp-judge` แต่ละแถวบอก "จะลงใน › ฉบับ…" เพิ่มด้วย `addSectionsToGroup`
- **โฟลเดอร์ของฉัน:** leaf ที่ไม่มี `parentId`
- **ไม่แสดง** `grp-forgotten` และโฟลเดอร์ `readOnly` อื่น
- แต่ละแถวบอกจำนวนมาตราในโฟลเดอร์ และถ้ามีบางมาตราที่เลือกอยู่แล้วให้บอก "มี ม.288 อยู่แล้ว" การเพิ่มข้ามมาตราที่มีอยู่แล้ว
- **ติ๊กได้หลายโฟลเดอร์** ปุ่มล่างสุด "เพิ่มใน M โฟลเดอร์" (กดไม่ได้ถ้า M = 0)
- **โฟลเดอร์ใหม่…:**
  - ไม่ใช่ Pro → เปิด `ProGateModal` ชุดเดิม
  - Pro → ช่องตั้งชื่อในแผ่นเดียวกัน แล้ว `createFolder` แล้วติ๊กโฟลเดอร์ใหม่ให้ทันที
- **เลิกทำ:** ลบเฉพาะคู่ (โฟลเดอร์, มาตรา) ที่การกดครั้งนี้เพิ่มเข้าไปจริง ด้วย `removeSectionFromFolder` leaf ที่ `ensureLeaf` สร้างขึ้นใหม่ไม่ต้องลบ

`showToast(message)` ใน `src/lib/toast.js` เพิ่มพารามิเตอร์ที่สามแบบไม่บังคับ `{ action: { label, onPress } }` และ `ToastHost` แสดงปุ่ม การเรียกแบบเดิมทำงานเหมือนเดิม

### 5.3 โฟลเดอร์ของฉัน

ปุ่ม 📁 มุมขวาบนของ `GalaxySelect` เปิดหน้ารายการโฟลเดอร์ (state ภายในหน้า ไม่ใช่ route ใหม่)

- แต่ละโฟลเดอร์เป็นการ์ด: ชื่อ จำนวนมาตรา และปุ่ม ▶ ฟังทั้งโฟลเดอร์ (ส่ง `label` = ชื่อโฟลเดอร์)
- กลุ่มสถิติกางเป็นชิปสีตามฉบับ แตะชิปเพื่อฟัง leaf นั้น
- แตะตัวการ์ดเปิด `FolderEditModal` ตัวเดิม

### 5.4 แยก logic ที่ใช้ร่วมกัน

`SelectScreen.jsx` (992 บรรทัด) ดึง logic ออกเป็น hook ที่ทั้งสองธีมใช้:

| hook | ดึงมาจาก |
|---|---|
| `useSectionSelection` | `selected`, `toggleSelect`, `selectAllInNode`, `nodeSelectionState`, ล้าง |
| `useTocNavigation` | `tocPath`, `currentNodes`, `atLeaf`, `visibleSections`, โหลด/ลองใหม่สารบัญ, ตัวกรอง |
| `useFolderPlayback` | `playLeaf`, `playGroup`, `playSelected` (ส่ง `label` ด้วย) |

หลังแยก `SelectScreen` ต้องหน้าตาและทำงานเหมือนเดิมทุกอย่าง

### 7.2 ตรวจด้วยตา

- **Classic ไม่เปลี่ยน:** ถ่ายภาพหน้าจอ 8 หน้า (home, select, book, reader, search, stats, bookmarks, settings) ทั้งโหมดสว่างและมืด ก่อนและหลังเปลี่ยนเป็น token แล้วต้องเหมือนกัน
- **Galaxy ทุกหน้า:** ไม่มีตัวอักษรเข้มบนพื้นเข้ม ไม่มีขอบหรือพื้นสีกระดาษหลงเหลือ รวมถึง modal, bottom sheet, `TtsPlayer` และ `AppTour`
- **ความลื่น:** วัด fps หน้าแรกบน Android รุ่นช้าด้วยดาว 13 ดวง เป้าหมายราว 60 fps ถ้าไม่ถึงให้ลดจำนวนดาวในฉากพื้นหลังก่อน
- **iOS:** ระบบสุริยะไม่ล้นจอที่ทุกขนาดตัวอักษร (`iphoneScale` / `ipadScale`)
- **ออฟไลน์:** ปิดเน็ตแล้วเปิดแอป ฟอนต์ Galaxy ยังเป็น IBM Plex Sans Thai

## 8. กรณีผิดพลาด

| กรณี | พฤติกรรม |
|---|---|
| ข้อมูลกฎหมายยังโหลดไม่เสร็จ | ดาวแสดงทันทีจาก `lawMeta` แถบชื่อฉบับแสดง "กำลังโหลด…" ดวงอาทิตย์กดได้เมื่อโหลดเสร็จ |
| ฉบับ `available: false` | ดาวจาง แตะแล้ว toast "เร็ว ๆ นี้" |
| อ่าน/เขียน localStorage ไม่ได้ | ใช้ค่าเริ่มต้น (Galaxy, ดาวครบ, ไม่มีคิวค้าง) ไม่พัง |
| สารบัญโหลดไม่สำเร็จในหน้าเลือกฟัง | ข้อความ "โหลดสารบาญไม่สำเร็จ" และปุ่มลองใหม่ เหมือน Classic |
| โฟลเดอร์ถูกลบจากอีกเครื่องระหว่างเปิด popup | เพิ่มเฉพาะโฟลเดอร์ที่ยังมีอยู่ toast บอกจำนวนที่เพิ่มจริง |
| ฟังอยู่เบื้องหลังนานจน JS หยุดทำงาน (Android ราว 80 วินาที คิว native เล่นต่อเอง) | `index` ยังไม่อัปเดตจนกว่าแอปกลับมา แล้ว `enterNativeItem` จะเรียก `onItemStart` ไล่ทุกมาตราที่ข้ามไป `index` จึงตามทัน ถ้าแอปถูกปิดทิ้งระหว่างนั้น ฟังต่อจะเริ่มจากมาตราสุดท้ายที่ JS เห็น ซึ่งอาจซ้ำไม่กี่มาตรา ยอมรับได้ |

## 9. ไม่อยู่ในรอบนี้

- ปรับ layout หน้าอ่านและตัวเล่นเสียงสำหรับ Galaxy (รอบนี้ได้แค่สีและฟอนต์)
- กลุ่มดาวความคืบหน้าในหน้าสถิติ
- Sync ค่าธีม ดาวที่โคจร และคิวฟังต่อขึ้น cloud
- ลากเรียงลำดับดาว
- ปุ่มฟังต่อแบบคิวในหน้าแรกของ Classic
- ผู้ใช้ปรับมุมกล้องเอง
